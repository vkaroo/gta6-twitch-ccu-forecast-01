Forecasts how many people will watch Grand Theft Auto VI live on Twitch in each hour of its release day, from the first hour's viewer count. It fits log-scale regressions and nearest-neighbour curves on dozens of past big game launches bundled with each case, and reports five quantiles per hour.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
